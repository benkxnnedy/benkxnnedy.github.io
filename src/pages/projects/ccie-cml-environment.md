## Design objective

The lab is intended to make configuration the beginning of the exercise, not the end.

Each topic is built with explicit failure scenarios: adjacency problems, unexpected path selection, redistribution errors, convergence behaviour, policy mistakes and verification gaps.

## Current scope

- Advanced IGP and BGP routing
- First-hop redundancy and convergence
- Multicast
- Datacenter technologies
- Automation and validation
- Linux-based packet and host troubleshooting
